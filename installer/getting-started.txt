AFNI for Windows - getting started
==================================

AFNI is a collection of command-line programs for analysing brain MRI data.
There are no windows to click: you type commands, and the programs read and
write data files.

After installation
------------------

1. Open the Start menu and choose "AFNI Command Prompt".
   A black window opens; AFNI programs work there.

2. Go to the folder with your data, for example:

       cd /d C:\Users\YourName\Documents\mri

3. Run a program, for example:

       3dinfo anat+orig
       3dcalc -help

Good to know
------------

- In AFNI commands, write paths with forward slashes: C:/data/anat+orig
- If you chose "Add AFNI to PATH", AFNI also works in any new Command Prompt
  or PowerShell window.
- The graphical viewer (afni) and SUMA are not part of this package.
- Documentation and tutorials: https://afni.nimh.nih.gov/
- To remove AFNI: Settings > Apps > Installed apps > AFNI for Windows > Uninstall.

This package was built from the official AFNI source code by the afni-win
project: https://github.com/notaskynet/afni-win
